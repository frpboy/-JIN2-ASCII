# Web port of "WILL YOU (Diamond Ring)"

Original ASCII artwork by **JIN2 · [@jin_22ee](https://instagram.com/jin_22ee)**, 2026.
Original source: [DIAMOND-RING](../) in [JIN2-ASCII/-JIN2-ASCII](https://github.com/JIN2-ASCII/-JIN2-ASCII).

This is an unofficial, faithful JavaScript/Canvas port of `diamond_ring.py` so the
piece can run in a browser. Made for personal, non-commercial use under the terms of
the original [LICENSE.txt](../LICENSE.txt): not sold, not used commercially, artwork
and code credited to JIN2.

Controls: **Space** pause · **R** replay · **S** save a PNG screenshot.

Static site: serve `index.html` + `ring.js` from any static host.

Audio: love-me.m4a is the personal clip ("Love Me" by JMSN) supplied by the
site owner for this proposal page. Browsers may require a tap to start sound.
